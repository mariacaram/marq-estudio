Desde acá editás la página: fotos, textos, servicios, precios y datos de contacto. Los cambios quedan online en aproximadamente un minuto.

¿Cómo consigo mi clave? (una sola vez)
  1. Entrá a github.com con la cuenta del estudio e iniciá sesión.
  2. Andá a Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Nombre: Panel Marq. Expiración: elegí 1 año.
  4. En Repository access elegí Only select repositories y marcá marq-estudio.
  5. En Permissions → Repository permissions → Contents elegí Read and write.
  6. Tocá Generate token, copiá la clave que empieza con github_pat_ y pegala acá arriba.
